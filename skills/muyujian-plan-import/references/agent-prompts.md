要求：

1. 每个可执行任务单独一行，只使用 `- [ ] 任务名称` 格式。
2. 如果我明确要求保留已完成事项，使用 `- [x] 任务名称`；否则只保留未完成事项。
3. 保留任务原意，以及必要的科目、章节、数量、时间等信息。
4. 删除序号、表格边框、说明段落、装饰符号和空任务。
5. 不要擅自拆分任务，不要补造我没有提供的截止日期或内容。
6. 最终先输出 Markdown 清单，随后用一句话说明识别出的任务数量；不要输出其他格式。

示例：

输入：数学第一章极限，今天完成 20 道基础题；背英语单词 50 个。

输出：

```markdown
- [ ] 数学：完成第一章极限基础题 20 道
- [ ] 英语：背单词 50 个
```

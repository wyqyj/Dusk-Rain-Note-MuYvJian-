# 暮雨笺计划 Markdown 整理技能

## 目标

把用户提供的学习计划、待办记录或 OCR 文本整理为可直接导入暮雨笺的 Markdown 任务清单。

## 输出格式

每个可执行任务单独一行，使用以下格式：

```markdown
- [ ] 任务名称
```

如果用户明确要求保留完成记录，可以使用 `- [x] 任务名称`。默认只输出未完成且仍有行动价值的任务。

## 处理规则

1. 保留任务的原意、科目、章节、数量和必要的时间信息。
2. 删除序号、表格边框、解释段落、装饰符号和空任务。
3. 不擅自拆分用户没有要求拆分的任务，不补造日期或任务内容。
4. 一个任务只能占一行；任务名称为空时不要输出该行。
5. 最终输出可直接保存为 `.md` 的清单，并在清单后简短报告识别出的任务数量。

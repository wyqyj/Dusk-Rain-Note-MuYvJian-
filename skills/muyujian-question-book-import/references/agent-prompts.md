# 外部 Agent 提示词

以下提示词由暮雨笺设置页提供。将其中的路径按实际位置替换后，发送给支持读取图片和本地文件的 Agent。

## 1. 让 Agent 读取并使用题册整理技能

```text
请读取并严格执行暮雨笺题册整理技能：<技能目录>\SKILL.md。
先读取 <技能目录>\references\question-book-format.md 和 <技能目录>\references\agent-prompts.md，确认输出格式后再处理资料。

任务：将我提供的题目资料整理为暮雨笺可导入题册。只输出题册目录及其文件，不要修改暮雨笺程序，也不要调用软件内的 OCR 或 AI 功能。

目标目录结构必须是：
<输出目录>\书名\分册名\questions.md
<输出目录>\书名\分册名\source\page-001.png

questions.md 必须使用 format: muyujian-question-book/v1，严格保留题目顺序；每道题必须有题干和标准答案。原始作答错误、不完整、无法确认或图片不清晰时，状态必须为 wrong，并在“错误原因”说明缺失内容；不得猜测标准答案。图片引用只能使用 source/ 下的相对路径。完成后逐项检查格式参考中的 Review Checklist。
```

## 2. 将图片中的题目整理为题册

```text
请把以下图片/扫描件整理成暮雨笺题册 Markdown。请先读取 <技能目录>\SKILL.md 和 <技能目录>\references\question-book-format.md，并完全遵守其格式。

输入资料：<图片或 PDF 路径>
输出目录：<输出目录>\书名\分册名\

执行要求：
1. 按原图和页码顺序识别每一道题，不合并、不跳号；题号使用 Q001、Q002 等。
2. 识别题干、原始作答、标准答案/解析和知识点标签。公式写为 LaTex 兼容 Markdown。
3. 只有原始作答明确正确时写“状态: correct”。作答错误、缺失、局部正确、无法辨认、或原图没有完整解答时一律写“状态: wrong”。
4. 所有 wrong 题都要写“### 错误原因”。没有足够证据时写清楚，例如“原图未包含完整解答，无法确认中间推导。”绝不编造答案或原因。
5. 将需要保留的原图复制到 source/，在题干中用相对路径引用，例如 ![原题图片](source/page-001.png)。
6. 完成后仅交付可导入的 questions.md 与 source/，并自检 front matter、章节、题号唯一性、题干、标准答案、状态和图片路径。
```

# 暮雨笺学习工作台文件案例

本目录提供学习工作台每个一级模块的可参考文件。所有日期均使用 `YYYY-MM-DD`。

| 模块 | 文件 | 用途 |
| --- | --- | --- |
| 总览 | `overview/workbench-state-example.json` | 工作台聚合状态示例 |
| 规划 | `plans/weekly-plan.md` | 可直接导入的 Markdown 任务清单 |
| 专注 | `focus/focus-record-example.json` | 专注记录结构示例 |
| 书架 | `books/bookshelf-example.json` | 书架与书本元数据示例 |
| 题册 | `question-books/calculus-volume-1/questions.md` | 可直接导入的题册 Markdown |
| 笔记 | `notes/chapter-review.md` | Markdown 学习笔记示例 |
| 画布 | `canvases/weekly-review-canvas.json` | 画布节点与连线结构示例 |
| 设置 | `settings/workspace-layout-example.json` | 考试阶段与目录设置示例 |
| 备份 | `backups/backup-manifest-example.json` | 综合备份清单结构示例 |

题册的完整生成要求见 `skills/muyujian-question-book-import/SKILL.md`。题册 Markdown 可以在工作台的“题册”页直接导入；计划 Markdown 可以在“规划”页导入。
